# Pouso — canal de atualizações

Este repositório público contém somente os arquivos necessários para instalar e atualizar o Pouso no Windows.

- O código-fonte não é publicado aqui.
- O aplicativo consulta `update-beta.json` somente quando o usuário escolhe **Verificar atualizações**.
- Todo instalador é validado pelo tamanho e pelo SHA-256 informado no manifesto.
- Nenhum download ou instalação começa sem confirmação explícita.

## Canal beta

O canal beta pode conter versões de teste. Os instaladores ainda não possuem assinatura Authenticode e o Windows
pode exibir um aviso do SmartScreen.

O Pouso e seu canal de atualização não são afiliados ao DropPoint ou ao Dropover.
